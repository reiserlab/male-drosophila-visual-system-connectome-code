# completeness

This folder contains scripts to track the completeness of the data set.

## connection-completeness_named

The script generates an excel file with all named neuron types in the optic lobe and some statistics about their completion status.

## generate_completeness_plots

Generate hexagonal heatmap plots and scatter plots of the synapses / connection completeness for one of the three main optic lobe neuropils. Used in Extended Data Figure 1 e,f.

## celltype_per_col_fig

Find columns in medulla and see which columnar neurons are "missing".
